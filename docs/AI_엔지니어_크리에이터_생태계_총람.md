### 2. 개발동생 (최준혁) — 국내 유일 하네스 엔지니어링 권위자
- **현직/이력**: AI 엔터프라이즈 교육·컨설팅 전문 기업 **데브브라더스(DevBrothers) 대표**. 삼성전자, SK, LG CNS, 현대자동차 등 국내 대기업 테크리드 및 개발팀 대상 AI 코딩 도구 도입 교육 전담.
- **채널 및 공식 링크**:
  - 유튜브: [개발동생](https://www.youtube.com/@개발동생) (구독자 3.8만 명)
  - 공식 웹사이트 & 블로그: [devbrothers.ai](https://devbrothers.ai/) (기술 인사이트 블로그 63편)
  - 문의: hello@devbrothers.ai
- **핵심 철학 및 기술**:
  - **"하네스 다이어트(Harness Diet) — 더 붙이기보다 덜어내라"**: 최신 LLM이 발전하면서 과거에 강제로 걸어둔 규칙("무조건 계획부터 세워라", "이 파일부터 읽어라")이 오히려 최신 모델의 자연스러운 추론을 가로막는 중복 지시가 됨. 프로세스가 실제 작업보다 비대해지는 함정을 경고.
  - **전역 컨텍스트 세금(Global Context Tax) 축소**: `CLAUDE.md`, `AGENTS.md`에 모든 지침을 넣으면 매 세션마다 수천 토큰이 낭비됨. 전역에는 '보안 철칙(Never), 빌드/테스트 기본 명령'만 남기고, 도메인 지식은 별도 스킬/참조 문서로 분리(Lazy-load)해야 함.
  - **Dynamic Workflows**: 대규모 리서치 시 16개 서브에이전트가 백그라운드에서 병렬 조사(Search-Fetch-Verify-Synthesize)하고 메인 세션에는 최종 1줄 결과만 리포트하여 컨텍스트 청결 유지.
  - **코드 과잉 생성 억제 (Ponytail 스킬 & YAGNI)**: AI가 지나치게 친절해 50줄짜리를 200줄로 부풀리는 병폐를 YAGNI(필요하기 전엔 만들지 마라), KISS 원칙으로 막아 코드와 토큰을 50% 절감.
  - **코드래빗(CodeRabbit)**: 장기 실행 에이전트가 생성한 PR을 자동으로 안전하게 코드 리뷰/검증하는 하네스 레이어.
- **우리 편대 적용점**: `AI_BRIDGE.md` 인계장 길이 다이어트, 노트북 Claude Code 세션 오염 및 토큰 낭비 방지.

### 3. 단테 (dante) — 실측 데이터 기반 실리콘밸리 시니어 개발자
- **현직/이력**: 네이버·쿠팡 개발자 출신 → 현재 **실리콘밸리 현업 시니어 개발자**. 《요즘 바이브 코딩 코덱스 완벽 가이드》, 《다시 깊게 익히는 인사이드 리액트》 저자. 인프런 1위 AI 강사 (수강평 4.9).
- **채널 및 공식 링크**:
  - 유튜브: [단테](https://www.youtube.com/@dante)
  - 공식 플랫폼: [dantelearn.com](https://dantelearn.com/)
  - 인프런: [inflearn.com/users/1138/@dante](https://www.inflearn.com/users/1138/@dante) (클로드 코드 실전, 밑바닥부터 만드는 AI 에이전트)
- **핵심 철학 및 기술**:
  - **"감으로 쓰지 말고 직접 재보고 써라"**: 입으로 설명하지 않고, 주요 기능마다 켜기 전·후의 **실행 시간, 토큰 소모량, 비용, 버그 발생 수를 숫자로 직접 측정**하여 표로 공개.
  - **실측 사례**: Haiku 5.5 vs Opus 5.5 작업 비용 29배 차이, Claude Code 첫 호출 38,085토큰 vs 미니 에이전트 629토큰 실측.
  - **하네스 완성 5단계**: 컨텍스트/스펙 하네스 → 검증 루프 (TDD·훅·CI) → 관측·디버깅 → MCP 서버 배포 → 비용 최적화.
  - **RAG의 진실**: 벡터 검색 단독 사용 시 정답 누락율(10.5%)을 하이브리드/리랭킹/GraphRAG로 극복하는 엔지니어링.
- **우리 편대 적용점**: 가치사슬 및 리포트 수집 파이프라인의 모델별 실제 비용·성능 벤치마크 기준 수립.

## 🎯 우리 편대(Clone Force 99) 4대 실전 실행 매뉴얼

1. **[하네스 다이어트 원칙]**: `AI_BRIDGE.md` 인계장은 핵심 요약과 상태만 남기고, 본 총람 문서처럼 방대한 자료는 `docs/`로 분리 보관하여 전역 컨텍스트 세금을 철저히 줄인다.
2. **[초경량 툴체인 장착]**: 에코(노트북 렉스)는 Vercel의 러스트 기반 `agent-browser`(`npx skills add vercel-labs/agent-browser`)를 도입하여 터미널 내 웹 자동화 시 메모리와 토큰을 10분의 1로 절감한다.
3. **[무중단 백업 파이프라인]**: FreeLLMAPI 및 오픈소스 라우터를 검토하여, 테크(우)나 에코가 사용량 한도에 부딪혔을 때 무중단 failover 체계를 구축한다.
4. **[에이전트 오케스트레이션 완성]**: 메타 알렉스의 원칙에 따라 [테크: 코드 설계] / [에코: 로컬 검증·실행] / [레커: 24시간 외근·알림·협업] / [크로스헤어: 24시간 침묵 데이터 수집]의 4인 분업 편대를 완성한다.
